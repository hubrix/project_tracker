* Decisions
** 2026-09-20 — Require both content review and the Git state check
The script can verify staging and cleanliness; the agent must verify meaningful
progress, truthful statuses, and captured follow-ups. The skill requires the
workflow gate and does not automatically install a Git hook.

** 2026-09-23 — org2gantt charts only open work under Workstreams
=Now= repeats Workstreams items and =Backlog=/=Decisions= are not scheduled
work. Closed items are pruned by default because TaskJuggler would schedule
them into the future from today; =--include-done= keeps them.

** 2026-09-23 — Missing efforts get a loud placeholder, not a guess
Trackers rarely carry =:Effort:=. Refusing to render would make the tool
useless on real trackers; a silent default would make the chart lie. Each
placeholder is printed to stderr.

** 2026-09-23 — Tracker mode schedules in agent time
Tracker items are done by agents in minutes to hours, at any hour, so a
person's 8-hour weekday calendar and a 1-day placeholder overstated every
chart. Tracker mode uses a 24/7 calendar and a 1h placeholder; a tracker that
sets any calendar property keeps its own. Plain mode keeps TaskJuggler's
defaults so it stays byte-identical to ox-taskjuggler.

** 2026-09-23 — =gantt= is an argument to the skill, not a second skill
=/project-tracker gantt= keeps one directory to install and the renderer
beside the instructions that call it; a separate =/gantt= skill would have to
be installed alongside and reach into =../project-tracker/scripts=. The skill
validator rejects frontmatter such as =argument-hint=, so the command is
named in the description and a =<command>= section.

** 2026-09-23 — org2gantt does not depend on Emacs
The first version exported through =emacs --batch= and a vendored
ox-taskjuggler. Rejected: Emacs is a heavy install for parsing an outline, and
the vendored GPL-3.0 Lisp would have split this MIT repository's licensing.
=orgtj.py= reimplements the exporter's rules in standard-library Python. It was
checked byte for byte against Emacs + ox-taskjuggler =e682a15= in a scratch
environment (7 fixtures, 220 random files, plain and tracker mode); the goldens
in =tests/= came from that run, so the tests do not need Emacs. orgtj fixes two
upstream dependency-parsing bugs: =BLOCKER= plus =depends= on one task, and
comma lists without spaces. Both are documented and tested. The report template
and example projects are original, not copied from the exporter or worg.
